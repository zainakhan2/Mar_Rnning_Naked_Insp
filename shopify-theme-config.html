⚙️ Shopify Dawn Theme Config

Copy-paste these settings into your Dawn theme to auto-apply StrideHer brand colors, fonts, announcement bar, and layout. No manual customization needed — just paste and save.

How to Apply This Configuration
3 steps, 5 minutes, and your store looks like the brand board.

Step 1: Open Theme Editor

Shopify Admin → Online Store → Themes → Dawn → Customize

Step 2: Apply Settings

In the theme editor, click Theme settings (gear icon at bottom-left). Then apply each section below by navigating to the matching section in theme settings.

Step 3: Apply Liquid Code

For advanced customizations (custom CSS, announcement bar styling): go to Online Store → Themes → ⋯ → Edit code → find base.css or custom.css and paste the CSS provided below.
